# Sistem Pencatatan Hasil Panen Digital

## Deskripsi

Sistem Pencatatan Hasil Panen Digital merupakan program sederhana berbasis Python
yang digunakan untuk mencatat hasil panen dan menghitung total nilai hasil panen.

## Fitur

- Input nama komoditas
- Input jumlah hasil panen
- Input harga per kilogram
- Perhitungan total hasil panen
- Perhitungan diskon

## Cara Menjalankan Program

Jalankan program menggunakan Python:

python panen.py
